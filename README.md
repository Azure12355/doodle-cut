# doodle-cut

A 30-second, hand-drawn style animation of a little orange box editing a video, **written entirely in code**. Every UI panel, character pose, camera move, piece of background music and sound effect is generated by code. There are no image, video, audio or font files in the repo (fonts load from Google Fonts at render time).

[中文说明](#中文说明)

- **Visuals:** [Remotion](https://www.remotion.dev/) (React + SVG/CSS), driven purely by the frame number
- **Music & SFX:** a ~400-line Node script that synthesizes a ukulele-style track (Karplus-Strong plucks, triangle bass, noise drums, bells, Schroeder reverb) and 8 sound effects, written straight to WAV
- **Output:** 1920×1080, 30 fps, 30 s, H.264 + AAC

## Storyboard

| Time | What happens |
|---|---|
| 0–4s | Empty editor. The box walks in and clips fly onto the timeline (it drags one in itself) |
| 4–8s | Camera zooms in, **SNIP!** cuts "the boring part zzz", the gap closes: *"much cleaner."* |
| 8–11s | Transitions tab. It places a Spin transition… and trips over its own feet |
| 12–15s | Text tab. "WAIT FOR IT" pops onto the cat clip |
| 16–19s | Stretchy arm cranks Sparkle, then **SHAKE: MAX**. Everything shakes. *"…nobody saw that."* |
| 19–24s | Playback, Zoom punch, EXPORT → 100% → DONE ✓ |
| 24–30s | Outro: big phone, "NAILED IT!", handwritten signature, confetti |

## Quick start

Requires Node 18+. No separate ffmpeg install is needed, because Remotion bundles its own.

```bash
npm install
npm run studio     # scrub frame by frame in Remotion Studio
npm run render     # synthesize audio + render out/demo.mp4
npm test           # unit tests (vitest)
```

`npm run studio` needs the audio files, so run `npm run audio` once first.

## How it's built

```
src/lib/timeline.ts   single source of truth: every key moment (frame number) + UI geometry
src/lib/state.ts      getEditorState(frame): pure function → what the editor shows this frame
src/lib/buddy.ts      getBuddy(frame): character position, eyes, stretchy arm, scissors, speech bubbles
src/lib/camera.ts     getCamera(frame): keyframed pan/zoom plus impact shakes
src/components/       purely presentational components (no timing logic inside)
audio/synth.mjs       procedural BGM + SFX → public/audio/*.wav
```

The main idea is that **animation is a pure function of the frame number**. Components only draw what `getEditorState` / `getBuddy` / `getCamera` return. That keeps the choreography testable (see `tests/state.test.ts`) and makes it easy to retime things. Change a value in `T` inside `timeline.ts` and the visuals and the sound effects move together.

The music runs at 120 BPM, so one beat is exactly 15 frames. That makes it easy to land actions on the beat.

### Customizing

- **Retime the story:** edit `T` in `src/lib/timeline.ts`
- **Camera path:** `KEYS` in `src/lib/camera.ts` (`[seconds, centerX, centerY, zoom]`)
- **Colors & fonts:** `src/theme.ts`
- **Signature / outro text:** `src/components/Outro.tsx`
- **Music:** chord progression, sections and melody at the top of the arrangement block in `audio/synth.mjs`

## 中文说明

一段 30 秒的手绘风动画：橙色方块小人独自剪完一条视频。整段**完全由代码生成**，包括界面、角色动作、运镜、背景音乐和音效。仓库里没有任何图片、视频、音频或字体文件，字体在渲染时从 Google Fonts 加载。

- **画面**：Remotion（React + SVG/CSS），所有动画都由帧号驱动
- **配乐与音效**：`audio/synth.mjs` 用纯数学合成尤克里里风格的 BGM（Karplus-Strong 拨弦、三角波贝斯、噪声鼓点、铃音、混响）和 8 种音效，直接写出 WAV
- **输出**：1920×1080，30fps，30 秒

### 使用

```bash
npm install
npm run audio      # 先生成音频
npm run studio     # 在 Remotion Studio 里逐帧预览
npm run render     # 渲染成片到 out/demo.mp4
npm test           # 单元测试
```

### 设计思路

核心原则是**动画 = 帧号的纯函数**：

- `src/lib/timeline.ts` 集中定义所有关键时间点，画面和音效都从这里取值，改一处就会一起变
- `getEditorState` / `getBuddy` / `getCamera` 是纯函数，根据帧号算出这一帧该画什么，可以单独做单元测试
- `src/components/` 只负责展示，不包含任何时间逻辑
- 音乐是 120 BPM，一拍正好 15 帧，动作卡拍很容易
